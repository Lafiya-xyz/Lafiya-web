## Issue #865: Oblivious HTTP for Card Scan Unlinkability

### Problem Statement

**Current State:**
- Card scan reveals to Lafiya: IP address + patient ID
- Hosting provider logs: IP + patient ID + timestamp
- Over time: Complete location history of patient emergencies
- No technical separation between "who scanned" and "what was scanned"

**Privacy Risk:**
```
Current flow:
  Responder (IP: 203.0.113.42) → Lafiya Server
  Request: GET /card/patient-abc-123
  
  Lafiya sees: IP=203.0.113.42, Patient=abc-123
  → "Someone at this location accessed this patient's card"
  → Over time: "This patient had emergencies at locations X, Y, Z"
```

**Threat Scenarios:**
1. **Location Tracking:** Build patient location history from scan IPs
2. **Emergency Pattern Analysis:** Infer medical conditions from scan frequency/location
3. **Insider Access:** Lafiya employees see who accessed what
4. **Subpoena Risk:** Logs can be compelled, linking responders to patients
5. **Hosting Provider:** AWS/Cloudflare sees all IP-patient pairs

**Impact:**
- Critical: Violates unlinkability requirement for sensitive data
- Privacy: Enables profiling of patient emergencies
- Trust: Responders may hesitate if activity is logged

### Technical Analysis

**Oblivious HTTP (RFC 9458):**
Separates "who" from "what" using three parties:
1. **Client:** Initiates request (responder with IP)
2. **Relay:** Sees client IP, doesn't see request content
3. **Gateway:** Sees request content, doesn't see client IP

**OHTTP Flow:**
```
1. Client encrypts request to Gateway's public key
2. Client → Relay: Encrypted blob (Relay sees IP, not content)
3. Relay → Gateway: Encrypted blob (Gateway sees content, not IP)
4. Gateway decrypts, processes, encrypts response
5. Gateway → Relay → Client: Encrypted response
```

**Result:** 
- Relay knows WHO (IP) but not WHAT (patient ID)
- Gateway knows WHAT (patient ID) but not WHO (IP)
- Neither party can link responder to patient

**Key Properties:**
- **Unlinkability:** IP address separated from request content
- **End-to-End Encryption:** Only client and gateway can read messages
- **Relay Independence:** Relay operated by third party (trust separation)
- **Standard Protocol:** RFC 9458, implemented in Cloudflare, Fastly

# Oblivious HTTP Specification for Lafiya

## Overview
Lafiya implements Oblivious HTTP (RFC 9458) to separate responder
identity from patient data access during emergency card scans.

## Architecture

### Three-Party System

1. **Client (Responder Device)**
   - Encrypts request to Gateway public key
   - Sends encrypted blob to Relay
   - Decrypts response from Gateway

2. **Relay (Third-Party Operator)**
   - Receives encrypted request from Client
   - Forwards to Gateway without decryption
   - Returns encrypted response to Client
   - Sees: Client IP, timestamp, blob size
   - Does NOT see: Patient ID, card data, request content

3. **Gateway (Lafiya Infrastructure)**
   - Receives encrypted request from Relay
   - Decrypts using private key
   - Processes emergency card lookup
   - Encrypts response with ephemeral key
   - Returns to Relay
   - Sees: Patient ID, card data
   - Does NOT see: Client IP, responder identity

### Message Flow

```
Client                    Relay                 Gateway (Lafiya)
  |                         |                          |
  |-- Encrypt(req, Kpub) -->|                          |
  |                         |-- Forward encrypted ---->|
  |                         |                          |-- Decrypt(Kpriv)
  |                         |                          |-- Process lookup
  |                         |                          |-- Encrypt(resp, Keph)
  |                         |<-- Encrypted response ---|
  |<-- Encrypted response --|                          |
  |-- Decrypt(Keph) ------->|                          |
```

### Cryptographic Details

- **Encryption:** HPKE (Hybrid Public Key Encryption)
- **Key Agreement:** X25519 or P-256
- **KDF:** HKDF-SHA256
- **AEAD:** AES-128-GCM or ChaCha20Poly1305
- **Gateway Key Rotation:** Every 7 days
- **Ephemeral Response Keys:** Per-request

import { webcrypto } from 'crypto';

/**
 * Oblivious HTTP (RFC 9458) client implementation.
 * Encrypts requests so relay sees IP but not content,
 * and gateway sees content but not IP.
 */
export class OHTTPClient {
  private gatewayPublicKey: CryptoKey;
  private relayUrl: string;

  constructor(config: {
    gatewayPublicKeyPem: string;
    relayUrl: string;
  }) {
    this.relayUrl = config.relayUrl;
    // Load gateway public key (would be async in real implementation)
    this.gatewayPublicKey = this.importPublicKey(config.gatewayPublicKeyPem);
  }

  /**
   * Make an OHTTP request.
   * Client encrypts, relay forwards, gateway decrypts.
   */
  async request(
    url: string,
    options: RequestInit = {}
  ): Promise<Response> {
    // 1. Create inner request
    const innerRequest = new Request(url, options);
    const innerRequestBytes = await this.serializeRequest(innerRequest);

    // 2. Encrypt inner request with Gateway's public key (HPKE)
    const encapsulatedRequest = await this.encapsulate(
      innerRequestBytes,
      this.gatewayPublicKey
    );

    // 3. Send encrypted blob to Relay
    const relayResponse = await fetch(this.relayUrl, {
      method: 'POST',
      headers: {
        'Content-Type': 'message/ohttp-req'
      },
      body: encapsulatedRequest
    });

    if (!relayResponse.ok) {
      throw new Error(`Relay error: ${relayResponse.status}`);
    }

    // 4. Receive encrypted response from Relay
    const encapsulatedResponse = await relayResponse.arrayBuffer();

    // 5. Decrypt response (Gateway encrypted it for us)
    const innerResponseBytes = await this.decapsulate(
      new Uint8Array(encapsulatedResponse)
    );

    // 6. Deserialize inner response
    return this.deserializeResponse(innerResponseBytes);
  }

  /**
   * Encapsulate (encrypt) request using HPKE.
   * This is a simplified version; real implementation uses HPKE library.
   */
  private async encapsulate(
    plaintext: Uint8Array,
    recipientPublicKey: CryptoKey
  ): Promise<Uint8Array> {
    // Generate ephemeral key pair for this request
    const ephemeralKeyPair = await webcrypto.subtle.generateKey(
      {
        name: 'ECDH',
        namedCurve: 'P-256'
      },
      true,
      ['deriveKey']
    );

    // Derive shared secret using ECDH
    const sharedSecret = await webcrypto.subtle.deriveKey(
      {
        name: 'ECDH',
        public: recipientPublicKey
      },
      ephemeralKeyPair.privateKey,
      {
        name: 'AES-GCM',
        length: 256
      },
      false,
      ['encrypt']
    );

    // Encrypt plaintext with derived key
    const iv = webcrypto.getRandomValues(new Uint8Array(12));
    const ciphertext = await webcrypto.subtle.encrypt(
      {
        name: 'AES-GCM',
        iv
      },
      sharedSecret,
      plaintext
    );

    // Export ephemeral public key
    const ephemeralPublicKeyBytes = await webcrypto.subtle.exportKey(
      'raw',
      ephemeralKeyPair.publicKey
    );

    // Encapsulated message format: [ephemeral_pk || iv || ciphertext]
    const encapsulated = new Uint8Array(
      ephemeralPublicKeyBytes.byteLength + iv.length + ciphertext.byteLength
    );
    encapsulated.set(new Uint8Array(ephemeralPublicKeyBytes), 0);
    encapsulated.set(iv, ephemeralPublicKeyBytes.byteLength);
    encapsulated.set(
      new Uint8Array(ciphertext),
      ephemeralPublicKeyBytes.byteLength + iv.length
    );

    return encapsulated;
  }

   * Serialize HTTP request to binary format.

  private async serializeRequest(request: Request): Promise<Uint8Array> {
    const method = request.method;
    const url = new URL(request.url);
    const headers = Array.from(request.headers.entries());
    const body = request.body ? await request.arrayBuffer() : new ArrayBuffer(0);

    // HTTP message format (simplified)
    const lines = [
      `${method} ${url.pathname}${url.search} HTTP/1.1`,
      `Host: ${url.host}`,
      ...headers.map(([k, v]) => `${k}: ${v}`),
      '',
      ''

    const headerBytes = new TextEncoder().encode(lines.join('\r\n'));
    const result = new Uint8Array(headerBytes.length + body.byteLength);
    result.set(headerBytes, 0);
    result.set(new Uint8Array(body), headerBytes.length);

    return result;

      const [key, value] = line.split(': ');
      headers.set(key, value);
    });

    return new Response(body, {

    const encapsulatedRequest = await request.arrayBuffer();

      headers: {

    });
  } catch (error) {

async function decapsulateRequest(encapsulated: Uint8Array): Promise<Uint8Array> {
  // Load Gateway private key from KMS
  const privateKey = await loadGatewayPrivateKey();

  // Extract ephemeral public key, IV, ciphertext
  const ephemeralPublicKeyLength = 65; // P-256 uncompressed point
  const ivLength = 12;

  const ephemeralPublicKeyBytes = encapsulated.slice(0, ephemeralPublicKeyLength);
  const iv = encapsulated.slice(ephemeralPublicKeyLength, ephemeralPublicKeyLength + ivLength);
  const ciphertext = encapsulated.slice(ephemeralPublicKeyLength + ivLength);

  // Import ephemeral public key
  const ephemeralPublicKey = await webcrypto.subtle.importKey(
    'raw',
    ephemeralPublicKeyBytes,
    {
      name: 'ECDH',
      namedCurve: 'P-256'
    },
    false,
    []
  );

  // Derive shared secret
  const sharedSecret = await webcrypto.subtle.deriveKey(
    {
      name: 'ECDH',
      public: ephemeralPublicKey
    },
    privateKey,
    {
      name: 'AES-GCM',
      length: 256
    },
    false,
    ['decrypt']
  );

  // Decrypt
  const plaintext = await webcrypto.subtle.decrypt(
    {
      name: 'AES-GCM',
      iv
    },
    sharedSecret,
    ciphertext
  );

  return new Uint8Array(plaintext);
}

function parseInnerRequest(bytes: Uint8Array): {
  method: string;
  url: string;
  headers: Headers;
  body: ArrayBuffer;
} {
  // Parse HTTP request format
  const text = new TextDecoder().decode(bytes);
  const [requestLine, ...rest] = text.split('\r\n');
  const [method, path] = requestLine.split(' ');

  const blankLineIndex = rest.findIndex(line => line === '');
  const headerLines = rest.slice(0, blankLineIndex);
  const body = rest.slice(blankLineIndex + 1).join('\r\n');

  const headers = new Headers();
  headerLines.forEach(line => {
    const [key, value] = line.split(': ');
    if (key && value) headers.set(key, value);
  });

  return {
    method,
    url: path,
    headers,
    body: new TextEncoder().encode(body).buffer
  };
}

## Issue #866: Pairwise Pseudonymous Patient Identifiers (PPID)

### Problem Statement

**Current State:**
- Partners (insurers, clinics, pharmacies) see globally stable patient IDs
- Two partners can join datasets on shared patient ID
- Patient cannot prevent cross-partner correlation
- Violates data minimization and purpose limitation

**Linkability Risk:**
```
Lafiya exposes:
  Partner A (Insurer):  patient_id = "abc-123"
  Partner B (Clinic):   patient_id = "abc-123"
  
Attack:
  Partner A ∩ Partner B on patient_id
  → "Patient abc-123 visited Clinic B, filed insurance claim"
  → Cross-partner profiling without patient knowledge
```

**Attack Scenarios:**
1. **Data Broker Collaboration:** Partners sell datasets to third party, joined on patient ID
2. **Merger/Acquisition:** Company acquires both partners, merges patient records
3. **Legal Compulsion:** Subpoena forces partner to reveal which patients use service
4. **Insider Threat:** Employee at partner correlates data across relationships

**Impact:**
- Critical: Enables unauthorized patient profiling
- Privacy: Violates purpose limitation (GDPR)
- Trust: Patients cannot control data sharing

### Technical Analysis

**Pairwise Pseudonymous Identifiers (PPID):**
Derive unique patient ID per partner using HMAC:

```
PPID = HMAC-SHA256(partner_secret_salt, internal_patient_id)

Example:
  Internal ID: "patient-00001"
  Partner A salt: "salt-partner-a-xyz"
  Partner B salt: "salt-partner-b-abc"
  
  PPID for Partner A: HMAC(salt-partner-a-xyz, patient-00001) = "ppid-a-123"
  PPID for Partner B: HMAC(salt-partner-b-abc, patient-00001) = "ppid-b-456"
  
Result:
  Partner A sees: ppid-a-123
  Partner B sees: ppid-b-456
  Partners CANNOT correlate: ppid-a-123 ≠ ppid-b-456
```

**Key Properties:**
1. **Pairwise:** Each partner gets different PPID for same patient
2. **Deterministic:** Same patient+partner always produces same PPID
3. **Unlinkable:** Cannot reverse PPID to internal ID without salt
4. **Collision-Resistant:** SHA-256 provides 128-bit security
5. **Partner-Specific:** Rotating partner salt invalidates all PPIDs

**HMAC-SHA256:**
- Input: 256-bit secret salt + patient ID string
- Output: 256-bit (32-byte) hash
- Representation: Base64url encoded (43 chars)
- Format: `ppid_{partner_id}_{base64url_hash}`

#### Phase 2: PPID Derivation Service

**File:** `lib/privacy/ppid.ts`
```typescript
import { createHmac } from 'crypto';

/**
 * Pairwise Pseudonymous Patient Identifier (PPID) service.
 * Derives partner-specific patient IDs to prevent cross-partner correlation.
 */
export class PPIDService {
  /**
   * Derive PPID for a patient-partner pair.
   * 
   * @param internalPatientId - Lafiya's internal patient ID
   * @param partnerSalt - Partner-specific secret salt (encrypted at rest)
   * @param partnerId - Partner identifier
   * @returns Pairwise pseudonymous identifier
   */
  derivePPID(
    internalPatientId: string,
    partnerSalt: string,
    partnerId: string
  ): string {
    // HMAC-SHA256(salt, patient_id)
    const hmac = createHmac('sha256', partnerSalt);
    hmac.update(internalPatientId);
    const hash = hmac.digest();

    // Base64url encoding (URL-safe, no padding)
    const base64url = hash
      .toString('base64')
      .replace(/\+/g, '-')
      .replace(/\//g, '_')
      .replace(/=/g, '');

    // Format: ppid_{partner_slug}_{hash}
    return `ppid_${partnerId}_${base64url}`;
  }

  /**
   * Derive PPID with caching.
   */
  async derivePPIDCached(
    internalPatientId: string,
    partnerId: string
  ): Promise<string> {
    // Check cache first
    const cached = await db.ppidCache.findUnique({
      where: {
        internal_patient_id_partner_id_ppid_version: {
          internalPatientId,
          partnerId,
          ppidVersion: await this.getCurrentVersion(partnerId)
        }
      }
    });

    if (cached) {
      return cached.ppid;
    }

    // Derive new PPID
    const partner = await db.partners.findUnique({
      where: { id: partnerId }
    });

    if (!partner) {
      throw new Error(`Partner not found: ${partnerId}`);
    }

    // Decrypt partner salt
    const decryptedSalt = await this.decryptPartnerSalt(
      partner.ppidSaltEncrypted
    );

    const ppid = this.derivePPID(
      internalPatientId,
      decryptedSalt,
      partner.slug
    );

    // Cache for future lookups
    await db.ppidCache.create({
      data: {
        internalPatientId,
        partnerId,
        ppidVersion: partner.ppidVersion,
        ppid
      }
    });

    return ppid;
  }

  /**
   * Reverse lookup: PPID → internal patient ID.
   * Only possible with partner salt (Lafiya can do this, partners cannot).
   */
  async reverseLookupPPID(
    ppid: string,
    partnerId: string
  ): Promise<string | null> {
    // Check cache (fastest)
    const cached = await db.ppidCache.findFirst({
      where: { ppid, partnerId }
    });

    if (cached) {
      return cached.internalPatientId;
    }

    // No reverse lookup without cache (would need to try all patients)
    return null;
  }

  /**
   * Rotate partner salt (invalidates all PPIDs for that partner).
   * Use case: Partner compromised, need to re-derive all PPIDs.
   */
  async rotatePartnerSalt(partnerId: string): Promise<void> {
    const partner = await db.partners.findUnique({
      where: { id: partnerId }
    });

    if (!partner) {
      throw new Error(`Partner not found: ${partnerId}`);
    }

    // Generate new salt
    const newSalt = crypto.randomBytes(32).toString('hex');
    const newSaltEncrypted = await this.encryptPartnerSalt(newSalt);
    const newVersion = partner.ppidVersion + 1;

    // Archive old salt
    await db.partnerSaltHistory.create({
      data: {
        partnerId,
        version: partner.ppidVersion,
        saltEncrypted: partner.ppidSaltEncrypted,
        validFrom: partner.updatedAt,
        validUntil: new Date()
      }
    });

    // Update partner with new salt
    await db.partners.update({
      where: { id: partnerId },
      data: {
        ppidSaltEncrypted: newSaltEncrypted,
        ppidVersion: newVersion
      }
    });

    // Clear cache for this partner (all PPIDs now invalid)
    await db.ppidCache.deleteMany({
      where: { partnerId, ppidVersion: partner.ppidVersion }
    });

    console.log(`Rotated PPID salt for partner ${partnerId}, version ${newVersion}`);
  }

  /**
   * Encrypt partner salt for storage.
   */
  private async encryptPartnerSalt(salt: string): Promise<string> {
    // Use KMS or application-level encryption
    // Placeholder: would use actual encryption
    return `encrypted:${salt}`;
  }

  /**
   * Decrypt partner salt from storage.
   */
  private async decryptPartnerSalt(encryptedSalt: string): Promise<string> {
    // Decrypt using KMS
    // Placeholder: would use actual decryption
    return encryptedSalt.replace('encrypted:', '');
  }

  private async getCurrentVersion(partnerId: string): Promise<number> {
    const partner = await db.partners.findUnique({
      where: { id: partnerId },
      select: { ppidVersion: true }
    });

    return partner?.ppidVersion || 1;
  }
}

export const ppidService = new PPIDService();

import { NextRequest, NextResponse } from 'next/server';
import { ppidService } from '@/lib/privacy/ppid';
import { verifyPartnerAuth } from '@/lib/auth/partnerAuth';

/**
 * Partner API: Get patient data.
 * Returns patient data with PPID instead of internal ID.
 */
export async function GET(
  request: NextRequest,
  { params }: { params: { partnerId: string; patientId: string } }
) {
  // Verify partner authentication
  const partner = await verifyPartnerAuth(request);
  if (!partner || partner.id !== params.partnerId) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 });
  }

  // Reverse lookup: PPID → internal patient ID
  const internalPatientId = await ppidService.reverseLookupPPID(
    params.patientId, // This is actually a PPID from partner
    params.partnerId
  );

  if (!internalPatientId) {
    return NextResponse.json({ error: 'Patient not found' }, { status: 404 });
  }

  // Fetch patient data
  const patient = await db.patients.findUnique({
    where: { id: internalPatientId },
    include: {
      visits: true,
      medications: true
    }
  });

  if (!patient) {
    return NextResponse.json({ error: 'Patient not found' }, { status: 404 });
  }

  // Derive PPID for response (should match request, but re-derive for consistency)
  const ppid = await ppidService.derivePPIDCached(
    patient.id,
    params.partnerId
  );

  // Transform response: replace internal ID with PPID
  const responseData = {
    id: ppid, // ← PPID, not internal ID
    name: patient.name,
    dateOfBirth: patient.dateOfBirth,
    visits: patient.visits.map(visit => ({
      id: visit.id,
      date: visit.date,
      diagnosis: visit.diagnosis
    })),
    medications: patient.medications.map(med => ({
      id: med.id,
      name: med.name,
      dosage: med.dosage
    }))
  };

  return NextResponse.json(responseData);
}
